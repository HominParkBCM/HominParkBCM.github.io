# hominparkbcm.github.io

Research site of Ho-min Park, Texas Children's Hospital Data Center, Baylor College of Medicine.

Plain static HTML served by GitHub Pages. No build step is needed to serve it.

## Editing

The pages are generated by `_build/build.py`, which holds the text, figure legends and the publication list as Python data.

```bash
cd _build
python3 build.py      # rewrites index.html and publications.html in the repository root
```

Inline figure schematics live in `_build/svg/`. Raster figures are in `assets/img/` as WebP.
